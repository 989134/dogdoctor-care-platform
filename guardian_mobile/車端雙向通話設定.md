# 樹莓派／Linux 車端雙向通話

App 現在有「與長者通話」，手機麥克風的聲音透過 WebRTC 傳到車端喇叭，車端麥克風的聲音回傳手機。通話只由管理員或照護者發起，唯讀帳號不開放。此功能不修改照護事件的接手／結案狀態，也不會自動呼叫 119。

## 車端設定

1. 把麥克風與喇叭接上樹莓派／Linux，先確認硬體能收音及播放。車端頁面會列出裝置，請選擇 `AB13X USB Audio` 麥克風與 `CD002-AUDIO` 喇叭；若 Chromium 不支援指定輸出，才改在 Linux 系統音訊設定中將 CD002-AUDIO 設為預設喇叭。
2. 在 App 以管理員登入，展開「與長者通話 → 車端配對」，產生配對金鑰。重新產生會撤銷舊車端並中止當前通話。
3. 樹莓派 Chromium 開啟與 App 相同主機的 `/vehicle` 網址。貼入金鑰，選擇車端麥克風與喇叭，按「啟用通話」並允許麥克風。接收頁啟用後允許已授權照護者發起通話，待機不傳送聲音。裝置選擇與音量只保存在該分頁的 `sessionStorage`。
4. App 顯示「車端已啟用」，照護者按「開啟車上喇叭通話」並授權自己的麥克風，即可雙向說話。可靜音自己的麥克風，或按「結束通話」。車端另有喇叭音量滑桿及停止接收按鈕。

例如已部署的 HTTPS 網址為 `https://您的網域`，可在樹莓派執行：

```sh
chromium --app="https://您的網域/vehicle"
```

有些系統執行檔名稱為 `chromium-browser`。這份專案不會自行在尚未連線的樹莓派安裝程式。配對金鑰保存在車端分頁的 sessionStorage，關閉分頁後需再次輸入；啟用通話也需人工按鈕授權，不會默默開啟麥克風。

## 網路需求

目前 `http://127.0.0.1:5006/` 只供這台開發電腦使用。樹莓派與手機需能存取同一個 HTTPS 主機，不能把 127.0.0.1 當成另一台電腦的地址。麥克風需要安全來源，請勿直接改成區域網路 HTTP 位址。

未設定 ICE servers 時先嘗試直接連線，適合可互通的網路；不同網路／行動網路可能需 STUN／TURN。由服務主機啟動前設定 `GUARDIAN_ICE_SERVERS` 為 JSON 陣列，再重啟：

```json
[{"urls":"stun:您的主機:3478"},{"urls":["turn:您的主機:3478?transport=udp","turns:您的主機:5349?transport=tcp"],"username":"您的帳號","credential":"您的密碼"}]
```

以上為格式範例，沒有預先提供可用的 TURN 伺服器或憑證。TURN credentials 會提供給已授權通話端，請使用專用且有限制的帳號，不可使用主機管理員密碼。HTTPS 部署方式沿用「手機App與通知設定.md」。目前尚未在真實樹莓派硬體與跨網路環境驗收。

## 連線與隱私

- 音訊由 WebRTC 傳輸；Flask 只交換連線描述，不錄音、不保存 SDP。稽核紀錄僅記錄誰發起通話。
- 每次最多一位照護者與一個車端通話。其他照護者會看到忙線。
- 手機掛斷或離開 App 前景即停止麥克風；車端恢復待機並停用音軌。車端「停止接收」會釋放麥克風。
- 網路中斷、金鑰撤銷、登入失效或服務重新啟動會結束通話，需重新發起。呼叫與車端 heartbeat 超過 20 秒即失效，連線未成功也會逾時關閉。
- 樹莓派接收頁與伺服器必須持續運作。此版使用單一服務程序的記憶體信令狀態，不能直接多 worker 部署。
- 喇叭與麥克風太靠近可能回授；已要求瀏覽器啟用回音消除與降噪，仍需在實際車體調整擺位與音量。

驗證包含權限、CSRF、車端配對撤銷、同時通話隔離、逾時與 ICE 設定格式。`test_intercom_browser.py` 會啟動兩個獨立 Chrome 瀏覽器環境，以模擬麥克風實際交換雙向音訊 RTP，並驗證靜音、掛斷與停止接收會正確停用或釋放音軌。測試沒有使用真實車端裝置；實際 AB13X 與 CD002-AUDIO 仍需在樹莓派上驗收。

一般測試：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

只執行雙瀏覽器 WebRTC 測試：

```powershell
.\.venv\Scripts\python.exe -m unittest test_intercom_browser -v
```

技術依據：[MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[WebRTC 音訊連線與信令](https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API/Signaling_and_video_calling)。
