# 監護者照護網頁分享版

目前可直接執行 `啟動照護網頁.ps1` 使用保存真實資料的本機網頁（5006）。新版分階段處理、10 分鐘逾時升級與第二聯絡人通知設定，請見 [照護流程串接.md](照護流程串接.md)。`run_demo.py`／5017 僅是先前保留的示範入口，請勿作為正式照護資料入口。

建議 Windows、Python 3.10（需含 tkinter），首次安裝需網路下載套件。請先完整解壓縮，不要直接在 ZIP 內執行。

## 啟動
在解壓後的 guardian_portal 資料夾開啟 PowerShell，依序執行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_guardian.py
```

瀏覽器開啟 http://127.0.0.1:5006 。首次啟動會產生 guardian_data/setup-token.txt，將內部設定碼填入登入頁，自訂帳號與至少 12 字元密碼。首次建立後設定碼即失效。

## 內容
總覽、事件管理、底部目錄、帳號權限、藥袋 OCR、藥品資料比對、效期核對、個人藥品清單、密碼修改與本機復原工具。包含原提供的藥品 XML 與健保異動 XLSX；為靜態資料，非即時更新。

本分享版未包含原使用者的帳號、密碼、設定碼、session key、藥品清單、照護事件、影像及日誌。對方首次開啟事件清單為空，屬正常現象。

若需接收自己的事件來源，將相容的 care_events SQLite 資料庫放在 mec_output 內；照片也必須存放於該目錄內，資料庫中的 snapshot_path 需為接收電腦的有效絕對路徑。這個 ZIP 不含完整機器狗控制或跌倒偵測服務。

## 測試與復原
```powershell
.\.venv\Scripts\python.exe -m unittest test_guardian -v
.\.venv\Scripts\python.exe guardian_reset_password.py
```

僅預設提供本機連線。已加入可安裝的 PWA、背景 Web Push 與簡訊傳送程式；手機連線所需的 HTTPS 網址和簡訊服務尚未設定，請見 [手機App與通知設定.md](手機App與通知設定.md)。網頁開啟時每 3 秒同步事件；到期提醒顯示於清單內。服務運作時每小時刪除過期事件影像。藥品用途來自資料庫，個人服用方式需按藥袋人工核對。
