# 車上語音與手機對話使用說明

## 已完成的功能

- 手機或電腦的 `/care` 頁面可以發送服藥、喝水、家人聯絡及緊急安撫提醒。
- 可輸入自訂文字，交由車上的樹莓派喇叭播放。
- 手機瀏覽器可把語音辨識成文字，送給 Gemini，再由車上喇叭朗讀回答。
- 可直接使用車上 AB13X 麥克風進行單輪或連續對話；每輪錄音六秒，回答播完才進入下一輪。
- 車上語音使用台灣女聲 `zh-TW-HsiaoYuNeural`，並稍微提高語速及音高。
- 可停止目前播放及清空待播放內容。
- 可從前端對車上麥克風錄製兩秒，只回傳 RMS 與峰值，不保存錄音。
- Gemini API Key 只保存在 Windows 電腦的 `.env`，不會送到手機或樹莓派。

## 設定 Gemini API Key

專案目前會從以下檔案讀取：

`C:\Users\lin40\Desktop\居家照護\homecloud\.env`

可直接把這一行填好：

```text
GEMINI_API_KEY=你的金鑰
```

也可以在 PowerShell 執行隱藏輸入工具，金鑰不會顯示在終端：

```powershell
cd "C:\Users\lin40\Desktop\居家照護\homecloud"
python set_gemini_key.py
```

修改後必須重新啟動 `run_homecare.py`。前端只會顯示「已設定／未設定」，不會回傳金鑰內容。

## 樹莓派音訊服務

把 `robot_audio_gateway.py`、`requirements-audio-pi.txt` 複製到樹莓派家目錄。先確認裝置：

```bash
arecord -l
aplay -l
```

安裝系統音訊套件與 Python 套件：

```bash
sudo apt update
sudo apt install -y espeak-ng alsa-utils mpg123 libportaudio2 portaudio19-dev
~/dogdoctor-venv/bin/pip install -r ~/requirements-audio-pi.txt
```

啟動服務：

```bash
ROBOT_AUDIO_INPUT_DEVICE='hw:3,0' \
ROBOT_AUDIO_OUTPUT_DEVICE='plughw:2,0' \
ROBOT_TTS_VOICE='zh-TW-HsiaoYuNeural' \
ROBOT_TTS_EDGE_RATE='+5%' \
ROBOT_TTS_EDGE_PITCH='+15Hz' \
~/dogdoctor-venv/bin/python ~/robot_audio_gateway.py --port 5002
```

`ROBOT_AUDIO_INPUT_DEVICE` 可填裝置編號或名稱的一部分。你的外接麥克風顯示為
`AB13X USB Audio (hw:3,0)`，喇叭為 `CD002-AUDIO (plughw:2,0)`。不設定輸入時會
使用系統預設麥克風，目前是 icSpring 攝影機內建麥克風。

健康檢查：

```text
http://樹莓派IP:5002/health
```

Windows `.env` 的位址必須與樹莓派一致：

```text
ROBOT_AUDIO_URL=http://10.129.211.235:5002
```

若之後設定 `ROBOT_AUDIO_TOKEN`，Windows 與樹莓派必須使用相同值。


電腦使用：

```text

```

```text
http://10.129.211.85:5003/care
```

若手機無法開啟，需允許 Windows 防火牆的私人網路連線。

## 音訊路徑

```text
手機麥克風
  → 瀏覽器語音辨識
  → Windows /care/assistant
  → Gemini
  → Windows /care/audio/speak
  → 樹莓派 :5002
  → 車上喇叭

車上麥克風
  → 樹莓派 :5002/microphone/capture
  → Windows /care/assistant/voice-turn
  → Gemini 語音辨識與陪伴回答
  → 樹莓派 Edge TTS 台灣女聲
  → CD002-AUDIO 車上喇叭
```

連續對話是半雙工設計，播放時不錄音，可避免車上喇叭的回答被麥克風再次送回 Gemini。
瀏覽器語音辨識的支援程度依手機瀏覽器而異；無法使用時仍可使用車上麥克風或文字輸入。
