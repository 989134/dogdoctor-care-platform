## 已完成

- 使用左右輪編碼器持續估計 `x`、`y` 與車頭角度。
- 接收前方超音波距離，建立 5 公分解析度的 2D 占用格地圖。
- 使用單目相機追蹤特徵並輸出定位可信度。
- 連續視覺失追時將定位標成不可用，供巡檢模組停止車輛。
- 起點畫面、車頭方向與行走距離同時符合條件時才接受閉環，降低相似門景誤判。
- 控制板回傳重複 `t_ms` 時安全忽略；時間倒退時停止使用舊定位基準。
- 整個定位服務為被動模式，不會傳送馬達指令。

## 即時啟動

先在樹莓派啟動：

```bash
/usr/bin/python3 ~/camera_server.py
NANO_SERIAL_PORT=/dev/ttyUSB0 ~/dogdoctor-venv/bin/python ~/ranger_gateway.py
```

在 Windows 確認以下網址能開啟：

- `http://樹莓派IP:5001/video_feed`
- `http://樹莓派IP:5000/health`
- `http://樹莓派IP:5000/telemetry`

再於 `homecloud` 啟動：

```powershell
python run_localization.py `
  --source http://樹莓派IP:5001/video_feed `
  --gateway-url http://樹莓派IP:5000 `
  --port 5005
```

瀏覽器開啟：`http://127.0.0.1:5005/localization`

## 即時驗收

1. 車輛靜止時，頁面顯示攝影機及遙測正常。
2. 手動前進時，`x`、`y` 位置連續變化。
3. 手動轉向時，角度連續改變。
4. 在障礙前停車，地圖出現深色障礙格，前方距離合理。
5. 遮住鏡頭數秒，定位應暫停或降低可信度。
6. 回到原始位置與車頭方向，閉環修正次數增加。

## 目前限制

- `navigation/calibration.json` 是暫定公尺校正，正式精度仍需重複直線量測。
- 超音波只有正前方一條射線，地圖會較稀疏。
- Depth Anything V2 目前只提供相對深度，不能直接當作公尺障礙距離。
- 閉環修正為即時起點重定位，尚未加入完整 pose graph 全域最佳化。
- 實車自主馬達輸出仍維持關閉，待即時定位驗收通過後才接入巡檢。
