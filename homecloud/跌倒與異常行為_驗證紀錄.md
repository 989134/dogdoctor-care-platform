## 本次補強

- 保留最近 2 秒的肩部與髖部垂直移動軌跡。
- 支援低視角下「全身變上半身」的情況。
- 只有肩部、髖部同時明顯下降，而且髖部接近畫面下緣時，才建立 `tracking_review`。
- 腳踝或膝蓋單純被遮住不會直接判定跌倒。
- `tracking_review` 在網頁顯示為「請人工確認」，可使用既有取消按鈕處理。
- 疑似跌倒時保存事件與第一張警報影像，程式重啟後仍保留未處理事件與剩餘倒數。
- 腿仍不可見時，軀幹恢復直立且髖部明顯升高並維持 0.5 秒，可標記重新起身。
- 上半身模式可辨識直立、彎腰、接近水平並累積久未活動時間，但不單憑局部姿勢判定跌倒。

## 其他已自動驗證項目

- 站立、坐下、彎腰與躺臥狀態。
- 正常休息區躺臥不觸發跌倒。
- 短暫動作不累積成跌倒事件。
- 久未移動、來回徘徊、警報取消與取消後暫停提醒。
- 鏡頭移動、影像中斷、低信心關鍵點與人物離開畫面時重設計時。

## 重新測試指令

在 `homecloud` 資料夾執行：

```powershell
python validate_care_video.py ".\test_videos\care_fall_01.mp4" --expect review
python validate_care_video.py ".\test_videos\care_adl_01.mp4" --expect none
python -m unittest discover -s tests -q
```

輸出中的 `passed: true` 代表結果符合預期。`tracking_review` 是低視角遮擋下的疑似跌倒確認事件，不等同醫療級的確診結果。
