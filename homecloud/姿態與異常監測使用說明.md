# 居家姿態與異常活動監測

本次新增人體骨架與連續時間判斷，沿用 MediaPipe Pose。提供一個只測試這兩項功能的入口，也已接入 `eldertest/main_homecare_audio_full.py`。原本 `app.py`、`eldertest/main.py` 與安全展示程式保留為舊版本，直接執行它們不會啟用這次的新監測介面。

## 啟動

在 Windows PowerShell 執行：

```powershell
cd 'C:\Users\lin40\Desktop\居家照護\homecloud'
.\start_homecare.ps1
```

然後開啟 http://127.0.0.1:5002/care 。預設影像來源為 `http://172.20.10.2:5001/video_feed`。

如果 PowerShell 的指令碼政策阻擋啟動，不需改系統政策，直接執行：

```powershell
& 'C:\Users\lin40\Downloads\cloud\cloud\.venv\Scripts\python.exe' 'C:\Users\lin40\Desktop\居家照護\homecloud\run_homecare.py'
```

IP 改變時加上 `--source http://新的IP:5001/video_feed`；USB 本機攝影機可用 `--source 0`。使用原專案 Python 3.10 環境，已確認包含 OpenCV 4.8.0 與 MediaPipe 0.10.14。另附最小依賴 `requirements-care.txt`；不需為姿態分析安裝或啟動 Torch、YOLO、Depth。

獨立入口只讀取影像並顯示本機警報，不控制馬達、不發送 LINE。關閉終端機或按 Ctrl+C 結束。

## 本次功能

- 即時骨架、身體傾斜角、疑似站立／坐姿／彎腰／躺臥狀態。
- 疑似跌倒：身體接近水平，且有短時間下降轉換，或出現在畫面較低位置；成立後進入 20 秒回應倒數。
- 久未移動：比較多個關鍵點與活動基準位置，預設連續 60 秒後進入確認倒數。細小位移會累積比較，避免緩慢移動被當作靜止。
- 疑似來回徘徊：在 30 秒觀察窗內檢查水平往返次數，預設至少 4 次方向反轉。這是畫面內來回移動提示，並非判定失智或認知狀態。
- 取消警報：倒數或警報成立後可按「我沒事／取消此警報」。同類事件暫停 60 秒，之後持續異常仍可再次提醒。
- 影像過期、人體關鍵點不足或離開畫面時停止累積時間。跌倒待確認事件不會因遮擋而消失，會等待取消、重新站起或倒數升級。
- 使用最新影格及獨立姿態執行緒，不等待 Depth 推論。

事件會保存到 `mec_output/care_events.sqlite3`；跌倒與追蹤中斷事件另存第一張警報影像。待處理事件在程式重啟後仍會恢復並延續剩餘倒數，網頁可查看最近事件與截圖。獨立影片展示依連接埠使用 `care_demo_連接埠.sqlite3`，避免和正式紀錄混在一起。

## 休息區與參數

在 `/care` 頁面按「框選床／沙發休息區」，再依序點影像中的左上角與右下角。設定會立即套用並保存至根目錄 `care_settings.json`；按「清除休息區」可恢復未設定狀態。也可以手動使用相對影像座標：

```json
"rest_zones": [[0.1, 0.4, 0.6, 0.9]]
```

代表左上 `(10%,40%)` 到右下 `(60%,90%)`。區域內平緩躺臥標為休息，且不觸發久未移動提示；明顯快速下降轉換仍可提示疑似跌倒。這些區域僅適用於固定視角，攝影機換位置後必須重設。未設定休息區時，画面低處的正常躺臥仍可能誤報。

`max_gap` 為允許的連續觀察間隔，預設 0.8 秒；過慢或斷續的畫面會重置判斷，不會把缺失影格當成持續異常。`visibility` 是關鍵點可見度門檻；目前要求肩、髖、膝、踝都足夠清楚，局部遮擋可能暫停追蹤。

## 完整照護版本

`eldertest/main_homecare_audio_full.py` 已接入相同監測服務，首頁新增 `/care` 連結。相機讀取執行緒將影格送給姿態執行緒，避免原先錯誤的 `check_immobility()` 呼叫及持續秒數／角度混用。

該版本沿用原本相機、控制板與外部服務設定。它的影像來源仍由原 `config.py`／環境變數決定，與獨立入口的預設 URL 不同。啟動前須先確認設定。完整版本在 Auto 模式或最後指令不是 stop 時，保守暫停姿態事件累積；請切換 Manual 並停止後觀察。

完整版本會在跌倒事件升級為高風險後，透過既有 LINE 設定通知指定的 `LINE_USER_ID`；每個事件成功送出一次，失敗最短間隔 10 秒重試。未設定收件人時不會改成廣播。取消只阻止後續提醒，不能撤回已送出的訊息。此次未發送實際通知。

修改前備份：`eldertest/main_homecare_audio_full.py.before_pose_care.bak`。

## 驗證與實際測試

已通過 76 項自動測試，涵蓋姿態、瞬間誤判排除、持續跌倒、椅上前傾跌倒、上半身久未移動、休息區、緩慢移動、追蹤中斷、警報取消、低視角重新起身、逾時升級、事件資料庫、三格警報影像、本機語音輸出、指定 LINE 收件人、來回移動及網頁 API。另用 2 支裝車視角影片與 4 支公開資料片段回放；目前跌倒正例都提出確認、日常動作負例都沒有事件，但樣本數仍不足以代表整體準確率。

建議依序測試：站立、坐下、彎腰、休息區躺臥、以影片或軟墊上的受控模擬呈現姿態變化、離開畫面、遮擋、警報取消。記錄每個情境的誤報、漏報與延遲。請勿要求長者真的跌倒。

目前是單人、固定視角的規則原型，未做多人身分追蹤或攝影機運動補償。實景地板位置、衣著、遮擋與光線仍需調整和驗證；不能保證區分所有躺臥與跌倒情境。

## 在網頁觀看測試影片

跌倒影片：

```powershell
python run_homecare.py --source ".\test_videos\care_fall_01.mp4" --port 5003
```

開啟 `http://127.0.0.1:5003/care`，先按「啟用語音詢問」。跌倒段落應出現詢問與20秒倒數；影片結束後停留在倒地畫面，倒數結束會升級高風險。

按 `Ctrl+C` 停止後，可改播日常動作影片：

```powershell
python run_homecare.py --source ".\test_videos\care_adl_01.mp4" --port 5003 --loop
```

日常動作影片應持續顯示坐姿等狀態，不應出現照護事件。

要測試由執行程式的電腦或樹莓派喇叭主動詢問，可在命令後加 `--local-tts`。完整版本則在根目錄 `.env` 設定 `CARE_LOCAL_TTS_ENABLED=1`；樹莓派需有可用音訊輸出與 eSpeak 後端。未加此設定時仍可按網頁的「啟用語音詢問與回答」，由瀏覽器播放問題並接收回答。

## 跌倒後分級處理

1. 疑似跌倒或快速下降後失去追蹤時，建立等待確認事件。
2. 網頁語音詢問「你還好嗎？」並顯示安全處置提示。
3. 20秒內按「我沒事／取消警報」，事件取消並暫停同類提醒60秒。
4. 20秒內重新偵測到穩定站立至少0.5秒，事件自動標記恢復。
5. 兩者都沒有時升級為高風險警報；完整照護版本透過既有 LINE 設定通知家人。

處置提示依循臺大醫院及衛生福利部國民健康署原則：先保持冷靜，不急著起身，檢查意識、出血和疼痛；意識不清、明顯出血、劇痛、疑似頭頸背髖受傷或無法起身時應求援。系統只提供提示與通知，不能判斷骨折或取代119與醫療人員。


## 筆電上半身觀察

新增自動分級：雙肩可見時即可觀察上半身，無須更換模型或開關。全身關鍵點都在畫面內且可見度足夠，才切回完整判斷。

上半身模式顯示可見部位活動、未活動秒數，以及可取得的傾斜角；髖部可見時可標示軀幹直立、彎腰或接近水平，髖部不可見而鼻子可見時只顯示「頭部相對雙肩傾斜角」。上半身可產生久未移動提醒，但不單憑水平姿勢判定跌倒，也不判斷徘徊。若先前已建立跌倒確認事件，腿仍在畫面外時，可用軀幹直立且髖部較危險位置上升至少畫面高度 15%、維持 0.5 秒，標記為重新起身。

筆電測試使用 `run_homecare.py --source 0`。更新後請先 Ctrl+C 停止原服務，再重新啟動並重新整理網頁。


## 追蹤中斷補強

近期有持續水平軀幹或肩髖同步快速下降至畫面低處的證據，接著失去關鍵點時，新增人工確認事件。這不是跌倒確診；系統會詢問本人，20 秒內沒有取消或重新起身才升級為高風險並由完整版本通知家人。網路中斷及載具移動不會因本規則新增提示。既有公開資料片段與本次裝車視角影片已通過回放測試；後續仍應依 `test_videos/TEST_MATRIX.md` 加入不同人物、距離、光線、動作與遮擋影片，才能評估準確率。
