# 機器狗視角照護測試矩陣

錄影時固定使用實際裝車高度與鏡頭角度。每個情境至少錄 3 次，包含不同距離、衣著與明暗；跌倒動作只由健康成人在軟墊上受控模擬，不要求長者實際跌倒。

| 類別 | 情境 | 預期結果 | 現況 |
|---|---|---|---|
| 正例 | 正面向前倒、側倒、背向倒 | 詢問是否需要協助 | 已有 1 段，另兩種待錄 |
| 正例 | 沿牆或椅子緩慢滑落 | 詢問或人工確認 | 待錄 |
| 正例 | 倒下後腿被家具或畫面邊緣遮住 | 人工確認，20 秒後升級 | 現有 `care_fall_01.mp4` 已通過 |
| 恢復 | 跌倒後自行重新站起 | 持續直立 0.5 秒後自動標記恢復 | 待錄 |
| 回覆 | 說「我沒事」 | 取消並暫停同類提醒 60 秒 | 程式測試通過，實際麥克風待測 |
| 回覆 | 說「救命／好痛／不能起來」 | 立即升級高風險 | 程式測試通過，實際麥克風待測 |
| 負例 | 正常坐下、抬腿、身體前傾 | 不出現跌倒事件 | `care_adl_01.mp4` 已通過 |
| 負例 | 彎腰撿物、綁鞋帶、跪下 | 不出現跌倒事件 | 待錄 |
| 負例 | 坐地、躺床、躺沙發 | 休息區內不警報 | 規則測試通過，實景待錄 |
| 遮擋 | 棉被、桌椅遮擋，人物離開畫面 | 不硬判確診；有危險動作證據才人工確認 | 規則測試通過，實景待錄 |
| 久未動 | 椅上或地面保持不動超過 60 秒 | 非休息區提出久未移動警報 | 待錄 |
| 徘徊 | 全身可見並在畫面內多次往返 | 達門檻後提出徘徊警報 | 待錄 |
| 環境 | 白天、夜間、背光、衣服與地面同色 | 記錄漏報與誤報 | 待錄 |
| 多人 | 家屬從旁經過或兩人交錯 | 不應把兩人的軌跡接成一次跌倒 | 待錄；目前仍是單人模型限制 |

每段影片記錄：影片名稱、人物、距離、光線、遮擋、預期事件、實際事件、事件秒數、是否誤報或漏報。累積足夠樣本後再計算召回率、誤報率與平均警報延遲。
