正式平台端點強制使用 HTTPS；只有 `localhost`／`127.0.0.1` 的契約模擬器允許 HTTP。

## 使用的官方能力

### IoT 智慧聯網大平台

官方公開說明包含 DMP 設備管理、RESTful、MQTT、WebSocket、資料加密與 PKI 雙向認證。實際事件 endpoint、tenant、裝置模型與 payload schema 必須由帳號內文件或技術窗口提供，因此程式採可配置的 `ChtIotEventSink`，不猜測正式網址。

### 電話連結服務 TAS

官方 OpenAPI server：

```text
https://tasapi.cht.com.tw/apis/CHTIoT
```

家屬通告使用：

```text
POST /phone-conn/v1/callout
X-API-Key: <API key>
```

程式送出的主要欄位：

```json
{
  "serviceNumber": "申請取得的服務號碼",
  "phones": ["家屬電話"],
  "ivrData": {
    "text": "銀髮守護犬偵測到高風險疑似跌倒……",
    "repeat": 2,
    "promptMode": "F"
  }
}
```

## 申請 TAS API key

官方 FAQ 指示寄信至 `linsandy@cht.com.tw`，主旨填「申請電話連結服務(TAS)」，並註明個人用戶或企業用戶。取得 API key 後先呼叫 `reg` API 租用服務號碼，再將服務號碼填入設定。

建議信件：

```text
主旨：申請電話連結服務(TAS)

您好，我是 2026 中華電信智慧創新應用大賽參賽團隊成員，
以個人用戶身分申請電話連結服務 TAS API key。

作品「銀髮守護犬」用於長照居家巡檢。當系統偵測到高風險疑似跌倒、
長者未在倒數時間內取消且沒有重新站起時，將使用 TAS callout API
撥打家屬電話並播放安全通告。

目前已依官方 OpenAPI 完成 X-API-Key、reg／callout 所需介面、
電話 payload、失敗重試及防重複通知程式，希望申請測試 API key
與服務號碼進行一次實際通告驗收。謝謝。
```

取得 API key 後可先列出既有服務號碼，避免重複租用：

```powershell
$env:CHT_TAS_API_KEY="<官方配發>"
python scripts\cht_tas_register.py --list
```

確認沒有可重用的號碼時再建立一組：

```powershell
python scripts\cht_tas_register.py --create
```

## 本機展示

啟動平台契約模擬器：

```powershell
$env:CHT_EMULATOR_API_KEY="自行設定的本機測試值"
python cht_platform_emulator.py --port 7100
```

執行一次事件＋電話通告契約測試：

```powershell
python scripts\cht_platform_smoke_test.py `
  --iot-url http://127.0.0.1:7100/v1/iot/events `
  --iot-api-key "自行設定的本機測試值" `
  --tas-url http://127.0.0.1:7100/apis/CHTIoT/phone-conn/v1/callout `
  --tas-api-key "自行設定的本機測試值" `
  --service-number 0281920000 --phone 0900000000
```

`0281920000` 與 `0900000000` 在此只用於本機格式測試；程式不會從模擬器撥出電話。

## 取得正式 TAS 資料後

在樹莓派或電腦的環境設定：

```text
CHT_TAS_API_KEY=<官方配發>
CHT_TAS_SERVICE_NUMBER=<reg API 租用取得>
CHT_TAS_PHONES=<家屬電話，多支以逗號分隔>
```

Edge Agent 會自動啟用 TAS。真實測試前先將收件人設成團隊自己的電話，確認通告內容、來電號碼、費用與重複通知控制；不得拿虛構或未經同意的電話測試。

## 取得正式 IoT 租戶後

設定：

```text
CHT_IOT_EVENT_URL=<租戶文件提供的 HTTPS 事件端點>
CHT_IOT_API_KEY=<平台配發的 API key>
```

若租戶 payload 並非目前的標準事件 JSON，只需在 `ChtIotEventSink` 加一層欄位映射；事件佇列、重試、去重與 TAS 通知不需重寫。
