# 監護者照護後台

在 homecloud 執行 `python run_guardian.py`，開啟 http://127.0.0.1:5006 。

首次登入：開啟 `guardian_data/setup-token.txt`，把設定碼貼入登入頁，設定帳號與至少 12 字元密碼。建立後設定碼會刪除。請自行保管密碼，不必傳給開發者。

## 已實作

- 讀取 mec_output 內 care_events 資料庫，整合事件、影像、風險與現場狀態。歷史測試事件也可能顯示，來源名稱會標在時間旁。
- 監護者「已收到／處理中／已處理」與備註另存，不修改現場警報。多位接收者的帳號與時間各自留存。
- 管理員可新增照護者、唯讀帳號及撤銷帳號；此版為一個家庭共用全部事件，尚無跨家庭隔離。
- 影像只允許已登入者存取，存取留下稽核紀錄。預設保存 30 天，可設 1～365 天；有事件讀取或更改期限時清除過期影像，服務沒有流量時不會定時清除。事件文字與處理紀錄保留。
- 開啟網頁時每 3 秒輪詢事件，可允許桌面通知；關閉瀏覽器後不會收到推播。
- 匯入提供的藥品辨識程式與資料，支援照片 OCR 及完整名稱／許可證查詢。上傳照片僅於記憶體處理，不另存。沿用原程式的唯一匹配規則，無法唯一確認不猜測。健保異動檔不是完整健保資料庫。

## 測試與界線

執行 `python -m unittest test_guardian -v`，涵蓋未登入保護、CSRF、唯讀權限、撤銷登入存取、路徑限制、影像期限及確認不取消現場警報。另已驗證資料載入與合成文字圖片 OCR；實際藥袋仍需使用者拍攝驗收。

此服務只監聽本機 127.0.0.1，供本機驗收。供遠端家屬使用前，需要 HTTPS、正式服務部署及帳號復原機制；不可直接把原有未加驗證的 /care 服務開到公網。此版沒有背景 Web Push、跨家庭資料隔離、即時攝影機或持續健康數據。

帳號雜湊、處理紀錄與 session key 位於 guardian_data，請勿公開或加入版本控制。原事件照片來自 mec_output，過期刪除會影響其他使用同一張照片的本機介面。


## 2026-09-15 更新

- 設定頁可修改密碼，成功後須重新登入；原有登入失效。
- 忘記密碼：電腦持有人在 homecloud 執行 `python guardian_reset_password.py`，互動輸入帳號、新密碼。不要把密碼傳給開發者。
- 使用 `python run_guardian.py` 啟動時，每小時執行影像期限清除（啟動即檢查），電腦與服務必須保持運作。此更新取代上述僅在請求時清除的描述。
- 手機連線尚待私人網路授權；目前仍監聽 localhost。Tailscale Serve 尚未啟用。背景 Web Push 尚未實作，手機關閉頁面不可保證通知。

## 風險區域第一版

事件頁提供「事件紀錄／風險區域」。先新增實際區域，再對事件指定區域、正式或測試用途，以及確認跌倒／疑似／誤報／無法確認。未標記資料不計入區域統計；統計依原事件發生時間取最近 30 天，重複判定不重複計數。

改善紀錄採每區域一個追蹤狀態的時間序列，保留歷次觀察、措施、負責人、複查結果與記錄時間；不是獨立多工單系統。完成複查不刪除歷史跌倒。

人工到點測試只顯示提醒，不控制馬達、不代表實車抵達、不發送家屬警報；同人同區域 60 秒內不重複記錄。正式到點 API 可記錄人工觀察次數，但尚未接上巡檢機器人；現有 UI 僅提供測試。沒有完整觀察時長，因此不計算跌倒機率。

位置來源目前是人工區域標記；未自動推測長者座標。實車巡檢點與區域 ID、地圖版本對應完成，且到點事件可靠後，才能接自動到點／離開再觸發規則。

## 數據分析
總覽提供最近 30 天的資料來源、人工判定、區域及每日事件圖。台灣時間分日。缺失接收時間不填零；前後改善資料不足時不生成成效。AI 按鈕使用服務環境中的 GEMINI_API_KEY 與可選 GEMINI_MODEL_NAME，只傳彙總數字。金鑰請在電腦自行設定，不放進網頁或分享 ZIP。AI 回覆是建議，非實驗證據。
