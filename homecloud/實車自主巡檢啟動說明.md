# 實車自主巡檢啟動說明

- Ranger V2 韌體已使用編碼器限制每次移動距離／轉角。
- 左右輪公尺換算、左轉與右轉角度補償已寫入 `navigation/calibration.json`。
- 即時定位整合攝影機、編碼器、超音波與單目視覺追蹤。
- 巡檢狀態機具備路徑規劃、巡檢點、停車觀察、障礙重規劃、定位中斷停止與緊急停止。
- 實車輸出預設關閉，只有加入 `--enable-motion` 才會控制車輛。
- 2026-09-15 已完成第一個實車自主巡檢點：兩次前進步進、約 16.2 公分、停車觀察 3 秒並正常結束；使用者確認實際移動與估計相近。
- 實車驗證結果保存在 `navigation/output/real_patrol_short_validation.json`。
- 2026-09-16 已完成兩點右轉 L 型實車巡檢：兩個巡檢點均停車觀察完成，最終估計位置 `(0.227, -0.230 m)`、角度 `-91.7°`；使用者確認約六個小步進後接近 90°，第二段比前次更接近直走。結果保存在 `navigation/output/real_patrol_l_validation.json`。
- 巡檢頁可按「保存測試紀錄」，把每次馬達指令、控制板回覆、當時座標、前方距離、任務事件與地圖摘要保存至 `navigation/output/real_patrol_evidence_日期_時間.json`。
- 巡檢點可選填 `yaw_deg` 指定觀察朝向；左轉為正、右轉為負。原地轉向後會重新取得超音波地圖，再規劃下一段路。
- 2026-09-16 超音波模組在 PORT 6 並確認 `_US6` 韌體已執行，但近距離紙箱下仍固定回傳 `400.0 cm`；更換線材後結果相同。因使用者確認感測器在另一個燒錄測試中曾有實際數值，現改回 Auriga 官方使用的 PORT 10，並以 `_US10_RAW` 韌體檢查原始回波。在取得有效距離前仍禁止自主移動。

## 每次開機的啟動順序

先在樹莓派啟動攝影機與 Ranger 閘道。Windows 端不必先知道樹莓派 IP，可執行：

```powershell
cd "C:\Users\lin40\Desktop\居家照護\homecloud"
python find_ranger_ip.py
```

程式只搜尋電腦目前所在的 `/24` 區網，並用 `/health` 回傳的 Ranger 控制板識別確認裝置。

### 1. 啟動即時定位

```powershell
python run_localization.py --port 5008
```

開啟：`http://127.0.0.1:5008/localization`

必須看到：

- 影像：正常
- 遙測：正常
- 定位狀態：正常
- 前方距離有數值
- 地圖有淺藍色可通行區域

前方距離不可固定顯示 `400.0 cm`。該值代表目前沒有取得有效回波，前置檢查應顯示失敗；此時不可進入實車模式。

目前導航韌體板名應為 `MBOT_RANGER_AURIGA_TELEMETRY_V2_ENCODER_STEPS_US10_GUARDED`。此版直接限制單次超音波等待為 30 ms、每 100 ms 取樣並短暫保留最近有效值；前進時若距離小於等於 25 cm，或連續兩次沒有回波，Auriga 會直接切斷馬達並回報停止原因。

### 2. 啟動唯讀巡檢

開另一個 PowerShell：

```powershell
cd "C:\Users\lin40\Desktop\居家照護\homecloud"
python run_real_patrol.py --localization-url http://127.0.0.1:5008 --port 5007
```

開啟：`http://127.0.0.1:5007/real-patrol`

頁面應顯示 `REAL_READ_ONLY`。此模式會計算路線與方向，但不會傳送馬達指令，`hardware_commands_sent` 必須維持 `0`。

### 3. 最後才啟動實車模式

先關閉唯讀巡檢，再執行：

```powershell
python run_real_patrol.py --localization-url http://127.0.0.1:5008 --port 5007 --enable-motion
```

第一次只設定車前方約 20 至 25 公分的巡檢點，旁邊需有人可立即按下網頁的「緊急停止」。完成短路線後，再設定房間巡檢點。

已完成短直線驗證後，可在網頁按「右轉 L 路線」載入下一個實車測試範本。範本會先前進到 `(0.25, 0)`、右轉至 `-90°` 並掃描，再前往 `(0.25, -0.25)`。完成或中斷後按「保存測試紀錄」。未掃描成安全區域的第二段不會前進。

## 斷線時的預期行為

- 樹莓派不在線：前置檢查失敗，任務不會開始。
- 攝影機或遙測中斷：巡檢轉為停止／定位失效狀態。
- 前方距離小於安全門檻：停止並重新規劃。
- 網頁緊急停止：立即送出 `stop` 並暫停任務。
